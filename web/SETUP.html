Rivera Quote Studio — office website & app

This folder is the complete app. Put it on the Synology once; after that every phone and PC in Rivera can open it as a website or install it as an app.

1 · Host it on the Synology (one time, IT / admin)

  1. DSM → Package Center → install Web Station. This creates the shared folder web.
  2. Copy this whole folder into web and name it rivera (so you have web/rivera/index.html).
  3. For phone/PC install the site must open on https: DSM → Control Panel → External Access → DDNS → add a free yourname.synology.me address, then Control Panel → Security → Certificate → Add → Let's Encrypt for that address.
  4. Open https://yourname.synology.me/rivera/ — the Rivera Quote Studio dashboard appears. Share this address with the sales team.

Inside the office only? http://NAS-IP/rivera/ works as a website, but browsers only offer “Install app” on https.

2 · Install the app

  1. Android (Chrome): open the address → menu ⋮ → Install app. The Rivera icon appears on the home screen.
  2. iPhone / iPad (Safari): open the address → Share → Add to Home Screen.
  3. Windows / Mac (Chrome or Edge): open the address → click the install icon in the address bar, or the Install app button in the left menu. It opens in its own window and can be pinned to the taskbar.

3 · Connect the Synology sales folder (each office PC, once)

  1. Map the NAS sales share as a drive (File Explorer → This PC → Map network drive → \\NAS\SALES), or use the Synology Drive Client sync folder.
  2. In the app: Synology & Files → Choose Synology folder → pick SALES\RCM\2) QUOTATION → Allow.
  3. Done. Packages are filed into F.Y 2026-27\014_date_CUSTOMER\, and the register and rate card are kept in _rivera_register.json in that folder, so every PC connected to it sees the same register. Next time, tap Reconnect once.

Phones can't write to network folders: on a phone, “Synology” downloads a ZIP with the same folder structure — open it in the Synology Drive or DS file app.

4 · Updating

Replace the files in web/rivera with a new version. Installed apps pick it up the next time they open (close and reopen once).

Office app vs. claude.ai version

  • Office app (this folder): works on the office network and offline after the first visit, writes straight into the Synology folder, reads photos and scanned PDFs with on-device OCR.
  • claude.ai version: adds the Rivera AI deep scan (best for photos, handwriting, unusual formats) and a team register stored online. Use Register → Backup (JSON) and Restore to move quotations between the two.
